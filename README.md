# Notes-App

A simple note-taking application. Users can create, edit, and delete notes with a responsive and modern interface.

---

## **Tech Stack**

- **Backend:** Express.js, SQLite  
- **Frontend:** Vue.js, Vue Router, TailwindCSS  

---

## **Features**

- Create new notes with a title and content  
- Edit existing notes  
- Delete notes with confirmation  
- Responsive UI with modern styling (TailwindCSS)  

---

## **Limitations**

- **Deployed on Render:** Initial start-up may take up to a minute due to Render's free service cold start.  
- **No user separation:** All notes are visible to everyone; there is currently no authentication or per-user storage.  
- **Database persistence:** Notes may be lost if the Render backend becomes inactive or restarts, as the SQLite database is not permanently stored.
